# Paquete de Checkpoint Documental

Este ZIP agrega al repositorio la documentación aprobada el 31 de julio de 2026 sobre la evolución de HMS AI Assistant hacia un Intelligent Case Engine.

## Instalación en Codespaces

1. Sube este ZIP a:

`/workspaces/hms-ai-assistant`

2. Ejecuta:

```bash
cd /workspaces/hms-ai-assistant
unzip -o hms-ai-assistant-checkpoint-2026-07-31.zip
git status
./tools/checkpoint/checkpoint.sh
```

El comando `unzip -o` colocará los documentos dentro de `docs/` sin borrar el resto del proyecto.
