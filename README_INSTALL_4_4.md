# HMS AI Assistant 4.4 — Login + UI responsive aprobada

## Incluye

- Login de escritorio y móvil.
- Acceso de demostración con cualquier correo y contraseña.
- Botón de conexión real con Google.
- Dashboard conectado a los casos reales.
- Navegación lateral en escritorio.
- Navegación inferior en móvil.
- Cuatro temas:
  - Midnight Social
  - Aurora Collaboration
  - Focus Accessible
  - Soft Graphite
- Tipografía y controles aumentados para accesibilidad.
- Responsive para escritorio, tablet y celular.

## Importante

El login por correo y contraseña es un prototipo visual almacenado en
localStorage. No sustituye la autenticación productiva de Supabase Auth.

La conexión de Gmail sí utiliza el OAuth real existente.
